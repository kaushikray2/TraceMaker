◆ decay_half()

void tmk::core::FlatU64U16::decay_half ( )
inline

Halve every value in place, erasing entries whose value reaches 0 – the history decay.

Exact-once: the sweep starts just after an empty slot (one always exists at the <= 70 % load the growth rule keeps) and walks the ring from there. Backward-shift deletion never moves an entry across an empty slot, so every entry an erase shifts into the sweep's path comes from its own cluster, ahead of the sweep – never from behind it, which is exactly what goes wrong across the wrap in a sweep from slot 0.

< the empty slot anchoring the sweep

< a full table cannot occur under the growth rule

< re-examine idx: the entry shifted into it is unvisited

std::size_t tmk::core::FlatU64U16::slot_count ( ) const
inline

Slot access for read-only sweeps (the heatmap build).

Do NOT erase in place during a hand-rolled sweep: backward shift moves an entry from a higher slot into the erased one, and across the ring wrap (last slot -> slot 0) that entry has already been visited, so it would be processed twice. Use decay_half() for in-place decay.
