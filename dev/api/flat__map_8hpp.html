Detailed Description

Flat open-addressing containers (Stage 2B: flat hash maps): a uint64 -> uint16 map and an int64-pair set, both linear-probing with backward-shift-free growth rehashing.

Linear probing over a power-of-two slot array with a splitmix64 finalizer for the probe start, backward-shift deletion (no tombstones), growth at 70 % load. Built for the route history map: ~1e8 finds per large job against std::unordered_map cost several seconds of pointer chasing; a find here is one or two cache lines. Key 0 is a valid key (occupancy is a separate flag, not a sentinel). Iteration is over raw slots for the one caller that transforms values in place (the history decay sweep); slot order is unspecified and no caller may depend on it.
